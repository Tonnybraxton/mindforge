# MindForge Typing Academy delivery

## Architecture

Build the requested sequence around a pure, deterministic typing engine. The engine owns focused exercise events, correction policies, elapsed time, character accuracy, speed and consistency. Original seeded content supplies lessons, keyboard drills, words, sentences, documents, numbers, symbols and all requested CodeType languages. Never execute typed code or commands.

Typing results extend existing game results so accounts, XP, levels, streaks, brain scores, statistics, exports and privacy rules remain shared. Store key and transition aggregates plus a compact personal replay timeline; capture no input outside the focused exercise. Separate practice from unpaused ranked sessions and validate ranked replay on the API.

## Delivery sequence

1. Shared contracts, engine and 60-second test with results and keyboard guidance.
2. Progressive touch-typing lessons, full keyboard, correction modes and adaptive drills.
3. Advanced text tests, endurance and CodeType.
4. Ten seeded campaign regions, at least 50 achievements, goals, daily/weekly challenges and workouts.
5. Arcade variants and original adventure exercises using the same validated engine.
6. Account leaderboards and real 2–8-player race rooms; no fabricated opponents.
7. Analytics, coaching, responsive/accessibility checks and complete integration tests.

## Work ownership

The app-builder coordination workflow applies. Engine specialist owns shared typing contracts/engine and unit tests. Content specialist owns original content, lesson/campaign definitions, analytics and achievements. Backend specialist owns API, repositories, migrations and API tests. Parent owns frontend, existing app integration and end-to-end verification. All specialists use shared contracts and communicate changes before altering another area.

## Verification

Test metric formulas, error/correction policies, deterministic/adaptive content, unlocks, privacy, replay validation, duplicate XP and race authorization. Exercise first lesson through XP, weak keys and next lesson; timed/code/arcade/race flows, desktop/mobile layouts and unchanged existing games. Build the PWA and document any unverified infrastructure explicitly.
